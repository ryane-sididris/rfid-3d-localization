# RFID – Voxel Classification

- `DS.csv` : premier dataset principal utilisé pour les expériences de classification de voxels.

- `ds_9March26.csv` : version améliorée du dataset avec réduction du data leakage.

- `ds_Tx(1).csv` : dataset contenant uniquement les données TX.

- `ds_Tx_Rx(1).csv` : dataset combinant les données TX et RX.

- `10.160.230.78(2).csv` : données RFID brutes/semi-traitées issues des acquisitions.

- `ds_elemen.csv` : dataset auxiliaire utilisé pour certaines analyses et expérimentations.

- `Notebook 1.ipynb` : notebook principal contenant preprocessing, entraînement et évaluation des modèles.

- `RX.ipynb` : expérimentations réalisées uniquement avec les données RX.

- `RXTX_true.ipynb` : expérimentations utilisant les données TX + RX.

- `Nb_ds_18feb_complet.ipynb` : notebook regroupant plusieurs pipelines et tests complets.

- `Notebook 1.html`, `profile_report.html`, `report.html` : exports HTML des notebooks et rapports d’analyse.
